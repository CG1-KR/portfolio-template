# Portfolio workspace

프로젝트를 선택해 상세 내용을 보는 한국어 앱형 포트폴리오 양식입니다.

- 흰색·하늘색의 깔끔한 워크스페이스 UI
- 프로젝트 목록, 프로젝트 상세, 프로필, 연락처를 별도 화면으로 분리
- 목록의 제목·요약·기간·역할은 기본 표시, 상세 보기 버튼으로 별도 화면 이동
- 상세 내용은 개요 / 진행 과정 / 결과·배움 탭으로 탐색
- 프로젝트·기술 검색과 분류 필터, 이전/다음 프로젝트 이동
- 데스크톱 사이드 메뉴와 모바일 하단 메뉴
- 주소의 # 경로로 상세 화면 직접 접근, 브라우저 뒤로가기·앞으로가기 지원
- 브라우저 편집, JSON 백업, 배포용 HTML 내보내기 유지
- 인쇄/PDF는 현재 화면과 선택된 상세 탭 기준
- 별도 빌드나 외부 라이브러리 없이 동작

첫 방문 화면과 메뉴 순서는 **소개 → 프로젝트 → 연락처**입니다.

## 화면 이동

- `#/profile`: 첫 화면, 기본 정보와 간단한 소개
- `#/projects`: 다음 화면, 프로젝트 목록
- `#/project/1`: 첫 번째 프로젝트 상세 (번호는 현재 목록 순서 기준)
- `#/profile/details`: 경험·기술 상세
- `#/contact`: 공개 연락처

## 사용 방법

1. GitHub Pages 사이트에서 **내용 편집**을 누릅니다.
2. `[ ]`로 된 안내를 본인의 실제 내용으로 바꿉니다.
3. **이 브라우저에 저장**으로 현재 기기에 임시 저장할 수 있습니다.
4. 다른 사람에게도 변경된 내용을 보여주려면 **배포용 HTML 내려받기**를 누릅니다.
5. 이 레포에서 **Add file → Upload files**를 눌러 내려받은 `index.html`을 올리고 커밋합니다. 기존 `index.html`을 교체하는 작업입니다.
6. GitHub Pages 배포가 완료되면 사이트에 반영됩니다.

> **중요:** 브라우저 저장은 GitHub 저장이 아닙니다. 편집 버튼은 누구나 자기 브라우저에서 사용할 수 있지만, 레포에 쓰기 권한이 없는 방문자는 공개된 파일을 바꿀 수 없습니다. 공유 PC에서는 임시 저장을 피하세요.

## 내용 백업과 복원

- 편집기 **저장 / 내보내기 → JSON 백업 내려받기**: 현재 작성 내용을 백업합니다.
- **JSON 백업 불러오기**: 저장해 둔 백업을 편집기에 불러옵니다. 저장 버튼을 눌러 화면에 반영하세요.
- 초기 빈 양식으로 복원하려면 이 레포의 `starter-data.json`을 내려받아 불러오세요.
- JSON만 GitHub에 올려서는 사이트가 바뀌지 않습니다. 최종 결과는 `index.html`로 내려받아 교체하세요.
- 브라우저 임시 저장본이 있으면 그것이 사이트의 최신 파일보다 먼저 보입니다. 배포된 최신 파일을 확인하려면 편집기의 임시 저장본 삭제 기능을 사용하거나 시크릿 창에서 여세요.

## GitHub에서 직접 수정하기

`index.html` 안의 `<script id="portfolio-data" type="application/json">` 블록이 내용 데이터입니다. 본문 디자인 코드를 건드리지 않고 이 JSON의 값을 수정해도 됩니다.

JSON 안에서 특수 문자를 사용할 때는 JSON 규칙을 지켜야 합니다. 특히 HTML 태그나 `</script>` 같은 문자열을 직접 넣을 때는 `<`를 `\u003c`로 이스케이프하세요. 브라우저 편집기의 HTML 내보내기는 이를 자동 처리합니다.

## 파일 구성

| 파일 | 용도 |
| --- | --- |
| `index.html` | 디자인, 기능, 배포할 실제 데이터가 포함된 독립형 페이지 |
| `starter-data.json` | 처음의 빈 양식을 복원하기 위한 백업 |
| `.nojekyll` | GitHub Pages에서 정적 파일을 그대로 제공 |
| `README.md` | 편집과 배포 안내 |

`index.html`은 PC에서 더블 클릭해 열어도 사용할 수 있습니다. 파일 직접 열기에서 브라우저 임시 저장이 제한되면 HTML/JSON 내보내기로 내용을 보관하세요.

## 배포

GitHub **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` 브랜치의 `/(root)`를 선택합니다. 저장 후 GitHub가 제공하는 사이트 주소로 접속하세요.

## 공개 전 확인

- 타인의 이름·경력·사진·프로젝트·수치가 들어 있지 않은지 확인하세요.
- 안내용 대괄호를 본인의 실제 내용으로 바꾸세요. 없는 경험은 삭제해도 됩니다.
- 고객 정보, 취약점 세부 정보, 내부 화면, 비공개 보고서 등 민감한 정보는 올리지 마세요.
- 실제로 검증한 성과만 적고, 링크가 올바르게 열리는지 확인하세요.
- 이 양식에는 로그인, 접근 제어, 비밀번호 보호 기능이 없습니다. 공개용 자료만 올리세요. 클라이언트에서 편집 화면을 숨기는 것은 보안 기능이 아닙니다.

## 디자인 및 원본 내용

일반적인 사례 중심 포트폴리오 구성을 참고해 레이아웃과 코드를 새로 작성했습니다. 참고 레포의 개인정보·경력·프로젝트 본문·암호화된 데이터를 포함하지 않습니다. 일러스트는 자체 작성한 SVG이며 외부 이미지나 추적 스크립트를 사용하지 않습니다.
